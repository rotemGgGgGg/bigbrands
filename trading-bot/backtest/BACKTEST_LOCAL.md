# בקטסט של כמה שנים — בחינם, על המחשב שלך

## 1. נתונים בחינם מ-NinjaTrader 8

1. מורידים ומתקינים את **NinjaTrader 8** (חינמי) מ-ninjatrader.com ונרשמים לחשבון סימולציה חינמי.
2. מתחברים: **Connections** → חיבור הדמו/סימולציה של NinjaTrader.
3. קובעים אזור זמן: **Tools → Options → General → Time zone** → ‏**Eastern Time (US & Canada)**.
   (אם תשאיר שעון ישראל — תוסיף בהרצה `--tz Asia/Jerusalem`.)
4. מורידים נתונים: **Tools → Historical Data → Download**
   - Instrument: ‏**MNQ** (חוזה רציף, למשל `MNQ ##-##`)
   - Data type: ‏**Minute**
   - טווח: כמה שנים אחורה (MNQ קיים מ-2019). אם ההורדה נעצרת — מורידים שנה-שנה.
5. מייצאים: באותו חלון → **Export** → אותו מכשיר, **Minute**, אותו טווח → שומרים קובץ ‎`.txt`.

הקובץ נראה ככה (שורה לכל דקה):
```
20240102 093100;16850.25;16852;16849.5;16851.75;312
```

## 2. Python על המחשב (Windows)

1. מתקינים Python 3.11 ומעלה מ-python.org — מסמנים **Add Python to PATH**.
2. בחלון פקודה (cmd):
   ```
   pip install pandas
   ```
3. מורידים את התיקייה `trading-bot/backtest` מה-repo (כל הקבצים בה) לתיקייה במחשב.

## 3. הרצה

```
cd C:\path\to\backtest
python run_years.py C:\path\to\MNQ.txt
```

מה יוצא:
- סיכום כולל: עסקאות, עסקאות לחודש, אחוז הצלחה, סה"כ R, דרואדאון מקסימלי, רצף הפסדים
- לפי תרחיש (S1/S2/S3) ולפי רמת כניסה (0.5 / 0.588)
- לפי שנה
- `trades_v8.csv` — כל עסקה בנפרד (פותחים באקסל)

אפשרויות:
- `--tz Asia/Jerusalem` — אם NinjaTrader לא מוגדר לשעון ניו יורק
- `--stamp open` — אם הקובץ מסמן את **פתיחת** הנר (NinjaTrader מסמן סגירה, והסקריפט מתקן אוטומטית)
- עובד גם עם ייצוא נתונים מ-TradingView ועם כל CSV עם עמודות datetime,open,high,low,close,volume

## מה חשוב לדעת

- נתוני דקה מומרים אוטומטית לנרות 5 דקות (נבדק מול נרות ה-5 דקות של Yahoo — זהה).
- אין עמלות בחישוב — ה-R הוא לפני עמלות.
- הבקטסט מניח מילוי לימיט בנגיעה. בפועל לפעמים צריך מעבר ברמה.
- המספרים שווים משהו רק מעל ~50 עסקאות לתרחיש.
