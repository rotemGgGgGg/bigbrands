# SP Model — בוט מסחר (MNQ, 5 דקות)

שלב 1: אסטרטגיה ב-TradingView לבדיקה מול מה שהיית לוקח ידנית.
השרת, PickMyTrade ותוכנת ה-Windows יבואו אחרי שהאסטרטגיה מאומתת.

## התקנה ב-TradingView

1. פתח גרף **MNQ1!** בטיים-פריים **5 דקות**, עם **Extended hours** פעיל (חובה — בלי זה אין את סשן לונדון).
2. Pine Editor → הדבק את `pine/sp_model.pine` → **Add to chart**.
3. אם יש שגיאת קומפילציה — שלח לי צילום/טקסט של השגיאה. הסקריפט נכתב בלי גישה לקומפיילר של TradingView.
4. Settings → Properties: קבע **Commission** לפי העמלות של Lucid (ברירת המחדל 0).

## מה רואים על הגרף

| סימון | משמעות |
|---|---|
| קווים אפורים | London high / low |
| רקע כחול | חלון מסחר 09:30–14:00 |
| תווית כתומה | Setup נדרך (תרחיש, כיוון, גודל רגל) |
| קו כחול / אדום / ירוק | כניסה / סטופ / טארגט — מתעדכנים כל נר |
| תווית כחולה | כניסה בוצעה: רמה, va_ratio, נרות עד מילוי, חוזים |
| ✗ אפור | Setup מת + הסיבה |
| תווית ירוקה/אדומה | תוצאה ב-R |

כל עסקה נרשמת גם ב-**Pine Logs** עם כל העמודות מסעיף 16 (כולל MFE/MAE ב-R).
הטבלה בפינה: מספר עסקאות, אחוז הצלחה, סה"כ R, דרואדאון מקסימלי — מול השערים בסעיף 17.

## הבדלים ידועים מול מסחר ידני

- **Volume Profile**: הסקריפט מפזר ווליום של כל נר 5 דק' שווה על הטווח שלו (לפי הספק). ה-FRVP המובנה של TradingView משתמש בנתוני טיים-פריים נמוך יותר, אז VAH/VAL יכולים להיות שונים מעט — וזה משנה עסקאות שבהן va_ratio קרוב ל-0.412 / 0.5 / 0.588.
- **מילוי לימיט**: הבקטסט ממלא כשהמחיר *נוגע* ברמה. בשוק אמיתי לפעמים צריך לעבור אותה.
- **סטופ וטארגט באותו נר**: הספק אומר להניח סטופ. מנוע הבקטסט של TradingView מנחש את סדר התנועה בתוך הנר, ולפעמים יבחר בטארגט.
- **כמות היסטוריה**: במסלול Essential/Plus יש ~10,000 נרות = ~7 שבועות של 5 דק'. זה ~13–15 עסקאות, לא 50.
