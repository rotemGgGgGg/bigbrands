# צ'אט עם בוט טלגרם מהמחשב

חלון במחשב שבו מדברים עם בוט טלגרם קיים. ההודעות נשלחות מהחשבון שלך, בדיוק כמו מהאפליקציה.

## הגדרה (פעם אחת)
1. היכנס ל-https://my.telegram.org עם המספר שלך, לחץ על **API development tools** ומלא את הטופס (שם כלשהו, Platform: Desktop).
   תקבל `api_id` (מספר) ו-`api_hash`.
2. הפעל את `TelegramBotChat.exe`. בהפעלה הראשונה הוא ישאל:
   - `api_id` ו-`api_hash`
   - שם המשתמש של הבוט (למשל `@some_bot`)
   - מספר טלפון, ואז הקוד שטלגרם שולחת לך (וסיסמת אימות דו-שלבי, אם יש לך)
3. מההפעלה השנייה הוא נפתח ישר לצ'אט.

כפתורים של הבוט מופיעים כ-`[טקסט]` בכחול, ולחיצה עליהם עובדת.

## אבטחה
- הקובץ `telegram.session` שנוצר ליד ה-exe = גישה מלאה לחשבון הטלגרם שלך. אל תשלח ואל תעלה אותו לשום מקום.
- כדי להתנתק: מחק את `telegram.session`, או בטלגרם: Settings → Devices → סיים את הסשן.
- לא לשלוח הודעות בכמויות/אוטומציה מהירה - זה החשבון האישי שלך.

## הורדת ה-exe
ב-GitHub: Actions → "Build Telegram bot chat .exe" → הריצה האחרונה → Artifacts → TelegramBotChat.
